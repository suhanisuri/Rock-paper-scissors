# Rock Paper Scissors

An interactive Rock Paper Scissors game built as part of The Odin Project curriculum to strengthen core JavaScript fundamentals and DOM manipulation skills through a fun browser-based project.

## Features

* Interactive gameplay against the computer
* Real-time score tracking
* Dynamic UI updates based on player choices
* Randomized computer move generation
* Instant win/loss/draw result display

## Built With

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Flexbox

## What I Learned

* DOM manipulation and dynamically updating webpage content
* Handling user interactions using event listeners
* Writing reusable JavaScript functions
* Working with conditional logic and game state management
* Generating random computer choices


## Project Goal

The goal of this project was to apply foundational JavaScript concepts by building a fully interactive browser game while improving frontend development skills and understanding how JavaScript interacts with the DOM.
